## Resource 1: Nominatim (OpenStreetMap geocoding)

**What it provides** (1–2 sentences):
Turns a place name or address (like "Suzzallo Library") into map coordinates (latitude and longitude) plus a full address. Uses OpenStreetMap data.

**Docs link:** https://nominatim.org/release-docs/latest/api/Search/

**Access:** No API key, free. Rate limit is max 1 request per second, and requests need a User-Agent that identifies the app. Results must credit OpenStreetMap ("© OpenStreetMap contributors").

**Sample response** (trim it to a few fields; paste the URL you called too):

URL: https://nominatim.openstreetmap.org/search?q=Suzzallo+Library+Seattle&format=json&limit=1

```json
[
  {
    "lat": "47.6558094",
    "lon": "-122.3080533",
    "type": "library",
    "name": "Suzzallo Library",
    "display_name": "Suzzallo Library, Spokane Lane Northeast, Central Campus, University District, Seattle, King County, Washington, 98195, United States"
  }
]
```

**Who could this data help, and with what?** (2–3 ideas; name real people and a real need, e.g. "first-year students who want to ...")

1. Students leaving campus late at night who want to request a NightRide by typing a building name like "Suzzallo" instead of an exact address, because they feel unsafe and want to book quickly.
2. Students living off campus who aren't sure if their apartment is inside the NightRide service area, and want to check before they request a ride, because the address lookup turns their location into coordinates the app can compare against the zone boundary.
3. New first-year students who only know their dorm by name (like "Maple Hall") and not its street address, who want to set it as their NightRide drop-off, because Nominatim can find the location from just the name.

**One risk** (missing data, bias, privacy, or reliability):
Missing or wrong data: If a student types a short or common name like "HUB," Nominatim might return the wrong place (or nothing for a newer building), so the ride could be sent to the wrong pickup spot. The app should show the full address and ask the student to confirm before booking.


## Resource 2: OSRM (Open Source Routing Machine)

**What it provides** (1–2 sentences):
Given a start and end point, it returns the driving route between them, including trip time (in seconds) and distance (in meters).

**Docs link:** https://project-osrm.org/docs/v5.24.0/api/

**Access:** No API key, free. The public demo server is for light use only: no fixed rate limit is published, but heavy use gets blocked, and it's "best effort" with no uptime guarantee. Requires a User-Agent and credit to OSRM/OpenStreetMap.

**Sample response** (trim it to a few fields; paste the URL you called too):

URL: https://router.project-osrm.org/route/v1/driving/-122.3080,47.6557;-122.3130,47.6650?overview=false

```json
{
  "code": "Ok",
  "routes": [
    {
      "duration": 233.3,
      "distance": 1337.2
    }
  ],
  "waypoints": [
    {"name": "Spokane Lane Northeast", "location": [-122.307664, 47.656036]},
    {"name": "University Way Northeast", "location": [-122.313062, 47.665]}
}
```

**Who could this data help, and with what?** (2–3 ideas)

1. Students deciding between NightRide and an Uber who want to see how long the NightRide trip would take, because if it's too slow they'd rather pay for an Uber.
2. Students waiting for a NightRide alone at night who want an alert when the shuttle is about to arrive, so they can wait safely inside a building instead of standing outside.
3. Students who feel unsafe walking home late at night and just want the fastest way home, who want to see the quickest route and trip time before choosing between walking or booking a NightRide.

**One risk** (missing data, bias, privacy, or reliability):
Reliability / missing data: UW doesn't publish live NightRide shuttle locations, so the app would have to estimate arrival time from a guessed starting point. If it says "2 min away" but the shuttle is really 15 min out, a student could end up waiting outside alone at night longer than expected, which is the exact situation the app is meant to prevent.
